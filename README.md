# I giorni della tua vita

Un calendario interattivo con viste giornaliera, settimanale e mensile. Ogni persona imposta la propria data di nascita e può aggiungere note ai periodi del calendario.

L’accesso online usa Google o un link inviato via email. Gli invii programmati da Gmail sono un’integrazione facoltativa, separata dall’accesso.

Le istruzioni per configurare e pubblicare l’app sono in [ATTIVAZIONE.md](ATTIVAZIONE.md).
